# AI Stock Watcher

แดชบอร์ดติดตามหุ้น ASTS, RKLB, IONQ และ OKLO พร้อมตัวชี้วัดทางเทคนิค

## สถานะโครงการ
เริ่มต้น repository สำหรับระบบติดตามราคาและสัญญาณทางเทคนิค โดยเน้นบริการฟรี

## ขอบเขต
- แสดงราคาหุ้นและเวลาที่ได้รับข้อมูล
- คำนวณ EMA 20/50, RSI 14 และ MACD
- แสดงสถานะเฝ้าระวัง ไม่ใช่คำแนะนำการลงทุน
- ออกแบบเป็น PWA สำหรับเพิ่มลงหน้าจอ iPhone

## ข้อจำกัดข้อมูล
แหล่งข้อมูลฟรีอาจมีความล่าช้าและข้อจำกัดด้านตลาด/ฟีด จึงต้องแสดง timestamp และเตือนเมื่อข้อมูลเก่าเสมอ ไม่เรียกข้อมูลว่า real-time แบบ consolidated หากไม่ได้ใช้ SIP feed

## ความปลอดภัย
ห้ามใส่ API keys, secrets หรือ private keys ลงใน repository ฝั่ง client ใช้ server-side secrets สำหรับ Worker เท่านั้น

## สถานะ
โครงสร้างแอปและระบบแจ้งเตือน push ยังต้องพัฒนาและทดสอบก่อนใช้งานจริง
